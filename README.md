# Officina Arcana

Scheda del personaggio di D&D in stile officina arcana: statistiche, battaglia con dadi 3D, zaino a griglia, officina dell'Artefice, grimorio e diario.

App web installabile (funziona anche offline). I dati di ogni giocatore sono salvati su Firebase e visibili solo a chi li ha creati.

Aprila da https://jackdaw2605.github.io/officina-arcana/
